# About
This page give you step-by-stop directions how to setup live stream using Restream.io

## What you need
1. You will need to login to our live stream computer. Username and password will be provided to you by the leadership team.
2. Use [[Planning Center]] and create event titles following this template - [[Event Title Template]]. You can use our [Livestream Titles Google Doc](https://docs.google.com/document/d/1jAcfpbZJpz-LKbh9nTjqA7-zTje5Mw9C2xGhLQegPpo/edit?tab=t.0#heading=h.fh324fmwpiha) to make it easier for you to create these titles.
3. Access to [[Restream.io]]

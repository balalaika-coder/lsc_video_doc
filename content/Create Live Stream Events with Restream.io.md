1. In Google Chrome, there is a bookmark setup to take you straight to our Restream.io page
   ![[Pasted image 20251021205326.png]]
2. Select any previously streamed event and duplicate it
   ![[Pasted image 20251022135209.png]]
3. Once duplicate copy is created, edit it and change the title
   ![[Pasted image 20251022135409.png]]
4. Open the event you created, make sure you enable channels where you want to stream.
5. Copy the key
   ![[Pasted image 20251022135537.png]]
6. Paste the key to the [[Web Presenter]] software and then [[Start Live Stream with Web Presenter]]
7. If you are creating an event for a future date or time, you can [[Schedule Future Event with Restream.io]]
